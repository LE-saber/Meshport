# 服务器管理控制台

控制台保留原 `Admin.dc.html` 设计的八页布局、图表、主题、图标与中日英切换，替换了模拟数据和本地状态操作。运行时仅请求同源 API，不依赖外部 CDN、字体服务或新的 Node 服务。

## 页面与实际管理操作

| 页面 | 数据与操作 |
|---|---|
| 概要 | 在线设备、P2P/中继会话、带宽、FRP、服务器资源、设备/等级待审、告警 |
| 设备管理 | 搜索、状态筛选、详情、编辑、启停、封禁、删除、密钥轮换、注册审批、注册码、分组、受支持的远程指令 |
| 通讯管理 | 真实会话、传输路径、消息与文件进度、断开会话 |
| FRP 管理 | frps/frpc 状态；映射创建、编辑、启停、删除和全部停止；节点创建、修改、启停、重启、配置及删除 |
| 权限与审批 | 等级请求批准、拒绝、撤销；直接授予等级；用户创建、修改、停用、密码重置、MFA 重置、删除 |
| 安全中心 | 登录记录、异常、密钥状态、轮换、MFA 策略、个人令牌创建/撤销、ACL、设备解封、自身 MFA |
| 监控与日志 | 实际时序图、P2P 成功率、连接失败、日志筛选/暂停、告警确认/解决、审计查看/导出 |
| 系统与 API | 服务、数据库、版本、备份创建/下载/删除、Webhook 创建/编辑/启停/测试/删除、API 密钥、API 文档、系统设置、已配置的签名更新 |

没有记录时显示空状态；没有采样时图表不生成曲线。未配置 TURN 或更新源时，显示服务端返回的未配置状态。版本表只显示实际已安装版本，不模拟「最新版」。

## 会话与权限

- 用户名、密码及可选 TOTP 登录，使用后端 HttpOnly Cookie；密码和会话令牌不写入 localStorage。
- 请求带 `X-Requested-With`；过期会话返回登录页。登录错误、API 错误和加载失败会展示出来。
- `viewer` 为只读，`operator` 可执行日常操作，`admin` 管理用户、节点和系统。服务器仍独立校验每个请求。
- 令牌、注册码、Webhook 签名密钥等仅在创建结果中显示；关闭后不会缓存在浏览器存储中。
- 实时数据通过 `/api/v1/admin/stream` WebSocket 获取，断线自动重连，15 秒轮询作为回退。
- 私有部署继续使用 SSH 转发与回环监听，参见 [PRIVATE_DEPLOY.md](PRIVATE_DEPLOY.md)。

## 构建与部署

```bash
make console
# 或仅生成 HTML：
python3 tools/build-console.py
```

源模板为 `web/console/console.template.html`，真实行为为 `app.js`，原设计的调色板、图标与翻译为 `design.js`。构建脚本将它们和登录/表单片段组合为 `index.html`。随设计导出的 React 18 与模板运行时保存在 `vendor/`，页面直接在浏览器运行。

将 `web/console/` 内容部署到配置项 `web_dir` 指定目录。仅更换静态页面无需重启服务端。先备份旧目录，再原子切换目录或符号链接；不要覆盖数据库、配置、密钥或现有 FRP。

`make release` 会构建控制台并将其打包为发行目录下的 `web/`。新安装时 `deploy/install.sh` 会复制到 `/opt/meshport/web` 并设置 `web_dir`。升级已有安装时，保留原 `web_dir` 配置，需要自行确认该目录指向新控制台。
